# ¿Chicas o chicos?

Web informativa y responsive sobre el uso del masculino y femenino plural en español, a partir del caso de una clase de 11 chicas y 1 chico.

## Publicación en GitHub Pages

1. Entra en https://github.com/new con la cuenta `sanchezanjana-coder`.
2. Crea un repositorio **público** llamado `masculino-vs-femenino-espanol`.
3. En el repositorio, pulsa **Add file → Upload files** y sube **`index.html` y `README.md`** (no el archivo ZIP).
4. Pulsa **Commit changes**.
5. Ve a **Settings → Pages → Build and deployment**.
6. Elige **Deploy from a branch**, rama **main**, carpeta **/(root)** y pulsa **Save**.
7. Cuando GitHub complete la publicación, la dirección esperada será:
   https://sanchezanjana-coder.github.io/masculino-vs-femenino-espanol/

> La URL anterior es la prevista por GitHub Pages, no una publicación ya comprobada.

No hacen falta instalaciones, Node, dependencias de compilación ni servidores. `index.html` contiene todo el diseño y contenido. La fuente web Google Fonts es opcional: sin conexión, se muestran fuentes locales alternativas.

## Contenido

- Distinción entre género gramatical y sexo.
- Explicación académica del masculino no marcado.
- Caso ilustrado de once chicas y un chico.
- Diferencia entre referencia, apelación coloquial y femenino inclusivo deliberado.
- Contraste entre RAE, FundéuRAE, Universidad de Piura y Universitat de València.
- Conclusión y bibliografía con enlaces directos.
